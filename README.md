# Walkscape-Wiki-Scrapper

[![GitHub Release](https://img.shields.io/github/v/release/Kyoro93/Walkscape-Wiki-Scrapper?color=f5a97f&label=latest%20zim&style=flat-square)](https://github.com/Kyoro93/Walkscape-Wiki-Scrapper/releases)

### WalkScape Wiki Offline (Kiwix)
I’ve successfully converted the WalkScape Wiki into an offline-friendly version! By using the Kiwix app (which reads .zim files), you can browse items, recipes, and guides without an internet connection.

**Automated Daily:** This process is now fully automated. A new, updated snapshot is generated and uploaded every single day to keep up with game updates!

---

## How to set it up

### 1. Download Kiwix
Get the mobile reader application for your respective device:
- **Android:** [Play Store](https://play.google.com/store/apps/details?id=org.kiwix.kiwixmobile)
- **iOS:** [App Store](https://apps.apple.com/app/kiwix/id997079563)

### 2. Get the Wiki file
Download the latest .zim data file directly from the GitHub Releases segment tray:
👉 **[Download Latest .zim here](https://github.com/Kyoro93/Walkscape-Wiki-Scrapper/releases/latest)**

### 3. Import to Kiwix
- Open the **Kiwix** app on your phone.
- Go to the **Device** (or **Local Files**) tab.
- If it doesn't appear automatically, click the **Select file** (folder icon) and pick the `.zim` file from your `Downloads` folder.

---

## Troubleshooting

- **Broken Layout?** If tables or images look too big, tap the **Reading Mode** icon (text/lines symbol) in the Kiwix top bar to simplify the view.
- **Outdated info?** The GitHub link above always points to the latest snapshot. Check back whenever you need the most recent data.
- **File not found?** Ensure the download finished completely. You may need to grant **"All Files Access"** to Kiwix in your phone settings.
